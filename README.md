# 영혼의 쉼터 — Soul Haven

최대 8명이 함께 플레이하는 한국어 협동 덱 빌딩 웹 게임 프로토타입입니다. 외부 npm 패키지 없이 Node.js 22 이상에서 실행합니다.

```bash
cd /home/potato/Projects/soul-haven
npm start
```

접속: http://localhost:3000

같은 네트워크의 친구는 `http://서버-PC의-IP:3000`으로 접속합니다. 각자 다른 브라우저/프로필이나 기기를 사용하세요. 다른 지역에서 함께 하려면 Node 서버를 외부 호스팅에 배포해야 합니다. 정적 파일만 배포하면 멀티플레이는 동작하지 않습니다. 서버는 `PORT` 환경 변수를 지원하며 `0.0.0.0`에 바인딩합니다.

## 플레이

- 전사: 최대 체력 85, 공격 카드 피해 +2.
- 마법사: 최대 체력 60, 매 턴 에너지 4.
- 도적: 최대 체력 65, 매 턴 카드 6장.
- 사신: 최대 체력 70, 승리 시 체력 7 회복.
- 기사: 최대 체력 95, 매 턴 방어도 4.

직업마다 시작 카드가 다릅니다. 빠른 대기열은 준비 상태로 입장하며 8명에 자동 출발합니다. 그 전에도 방장이 출발할 수 있습니다. 초대 방은 6자리 코드를 공유하고 모두 준비한 뒤 시작합니다. 1인 플레이도 가능합니다.

각 플레이어는 자기 손패와 에너지를 사용합니다. 공격 대상은 공동의 적 한 명입니다. 전원 턴 종료 시 적이 모든 플레이어를 공격합니다. 방어도는 적 공격을 막은 후 다음 턴에 초기화되고, 손패는 버린 후 다시 뽑습니다. 뽑을 카드가 없으면 버린 카드를 섞습니다.

방장이 경로를 선택합니다. 전투 승리 시 골드와 카드 선택 보상을 받습니다. 정예 적은 더 많은 골드를 줍니다. 3번째와 6번째 장소에는 상점 또는 휴식이 있으며, 4번째 장소에서 이벤트를 선택할 수 있습니다. 7번째 장소는 최종 보스입니다.

상점 상품은 플레이어마다 별도입니다. 카드 구매 50 G, 체력 25 회복 30 G, 카드 제거 45 G입니다. 각 상품/서비스는 방문당 한 번 이용할 수 있습니다. 최소 덱 크기는 5장입니다. 동료가 전부 방문을 마치면 다음 경로로 이동합니다.

쓰러진 동료는 승리 시 최대 체력의 25%로 부활합니다. 전원 사망 시 패배합니다. 새로고침하면 로컬 브라우저에 저장한 세션으로 재접속합니다. 45초 이상 연결이 끊긴 플레이어는 전투 턴 및 보상/방문 선택을 자동으로 넘기며, 방장이 끊기면 연결된 팀원에게 방장을 넘깁니다. 진행 중 나가기는 재참가할 수 없습니다.

## BGM

사용자 지정 영상: https://www.youtube.com/watch?v=DR-wOshDxSQ

상단 `♫ BGM` 버튼을 누르면 YouTube 공식 임베드 플레이어가 열립니다. 플레이어에서 재생, 음량, 음소거를 조절하세요. 재생 중 패널을 닫아도 음악은 유지됩니다. 자동 재생 차단을 피하기 위해 직접 재생 버튼을 누르는 방식입니다. 반복 재생 URL을 설정했습니다. 영상 제공자의 임베드 허용 여부, 지역 제한, 광고, 네트워크에 따라 재생이 달라질 수 있습니다. 음원을 추출하거나 프로젝트에 복제하지 않았습니다. 임베드가 차단되면 패널의 YouTube 링크를 이용하세요.

## 검증

```bash
npm test
```

게임 규칙과 HTTP 서버를 검사합니다. `tests/browser.mjs`는 현재 PC에 이미 설치된 Playwright와 Google Chrome을 사용합니다. 다른 환경에서는 Playwright 설치 후 import 경로와 Chrome 경로를 수정하세요. 실행 중인 서버에 연결해 두 브라우저 협동 전투, 보상, 재접속, 모바일 화면을 검사합니다.

```bash
node tests/browser.mjs
```

화면 캡처는 `artifacts/`에 저장합니다.

## 구조 및 현재 범위

- `game.js`: 직업, 카드, 전투, 경로, 보상, 상점 규칙.
- `server.js`: 서버가 검증하는 행동 API, 방/대기열, 세션, 재접속 처리.
- `public/`: 반응형 화면, SVG 캐릭터, YouTube 플레이어.
- `tests/`: 규칙/서버 테스트 및 브라우저 시나리오.

현재는 1막 7개 장소, 5직업, 13종 카드, 방당 최대 8명입니다. 실시간 상태는 1.2초 간격으로 갱신합니다. 모든 방과 게임 진행은 서버 메모리에 있으며 서버 재시작 시 초기화됩니다. 접속자가 한 시간 동안 없는 방은 정리됩니다. 계정, 영구 저장, 장비/유물, 카드 강화, 직업 전직, 여러 적 선택 공격, 공개 배포는 아직 포함하지 않았습니다. 방 코드는 같은 서버에 접속한 사람끼리 사용합니다.
